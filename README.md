# Tripleten web_project_around_es

Around The U.S. es un proyecto de una galería virtual diseñada para explorar distintos lugares representativos de Estados Unidos. El sitio fue desarrollado utilizando HTML, CSS y JavaScript, tecnologías que hicieron posible crear una interfaz atractiva, responsiva e interactiva para el usuario. Visitanos en https://github.com/LilianGalaviz/web_project_around_es.git
