# Tripleten web_project_around_es

##Descripción
Around The U.S. es un proyecto de galería virtual diseñada para explorar distintos lugares representativos de Estados Unidos.
##Funcionalidad
En ella el usuario puede: agregar tarjetas, dar like, eliminar imagenes, ver la imagen ampliada, editar perfil.
##Tecnologías
El sitio fue desarrollado utilizando HTML, CSS y JavaScript, tecnologías que hicieron posible crear una interfaz atractiva, responsiva e interactiva para el usuario. Visitanos en https://liliangalaviz.github.io/web_project_around_es/
